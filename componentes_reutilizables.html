Guía de Componentes Reutilizables

Plan de Refactorización y Modularización - Portal de Aprendizaje HTML5 / CSS3

1. Cabecera Global (<header>)

  • Navegación entre Módulos (.nav-modulos): Botones flotantes de retroceso y salto entre secciones (← Portal, Módulo 1, Módulo 2, etc.).
  • Menú de Pestañas Internas (.menu-navegacion): Estructura horizontal (<nav><ul><li><a>) con clase dinámicamente asignada (.activo) según la página visitada.
  • Marca / Título del Sitio (<h1>): Encabezado principal estilizado en color blanco brillante sobre fondo oscuro.

2. Pie de Página Global (<footer>)

  • Pie de página estandarizado: Centralización de aviso de copyright, año y créditos del curso en un único bloque reutilizable en todas las vistas.

3. Tarjetas de Contenido (.tarjeta-contenido / .card)

  • Contenedores universales: Estructura estándar para envolver temáticas, ejercicios interactivos o explicaciones de APIs manteniendo sombras, radios de borde y paddings uniformes.

4. Botones y Elementos de Acción (.btn-nav, .btn-acceso)

  • Estilos de interacción: Botones primarios, secundarios y hovers unificados centralizadamente para evitar redundancia de clases CSS.

5. Hoja de Estilos Base (base.css)

  • Variables CSS (:root): Paleta de colores globales (azules, grises, fondos oscuros), tipografía base y reseteo inicial (box-sizing, margin: 0).
