3.8 Consumo de Servicios Web con Fetch API

Lección práctica de comunicación asíncrona

La Fetch API proporciona una interfaz JavaScript para acceder y manipular partes del canal HTTP, tales como peticiones y respuestas. Utiliza Promesas y resulta mucho más potente y flexible que el antiguo objeto XMLHttpRequest.

Estructura Básica

fetch('https://api.example.com/data')
  .then(response => response.json())
  .then(data => console.log(data))
  .catch(error => console.error('Error:', error));
