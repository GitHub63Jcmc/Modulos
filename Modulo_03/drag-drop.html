3.9 API de Drag & Drop (Arrastrar y Soltar)

Lección práctica de interactividad avanzada

La API de Drag and Drop de HTML5 permite a los usuarios arrastrar elementos de la página y soltarlos en zonas de destino designadas mediante eventos específicos como dragstart, dragover y drop.
