3.1 Introducción al elemento canvas y su contexto de dibujo

Lección práctica de gráficos y dibujo 2D

La etiqueta <canvas> reserva en la página un lienzo de píxeles sobre el que se dibuja desde JavaScript: gráficos, juegos, editores de imagen, firmas digitales... Se declara con sus dimensiones (ej. <canvas id="lienzo" width="600" height="400"></canvas>).

Si no se indican, mide 300×150 y el texto interior sirve de alternativa para navegadores sin soporte. Conviene fijar el tamaño con los atributos, no solo con CSS: escalarlo con CSS deforma y pixela el dibujo.

El Contexto de Dibujo (2D)

El lienzo por sí solo no hace nada; para dibujar se pide su contexto, el objeto que contiene todos los métodos de dibujo. El bidimensional se obtiene con const ctx = lienzo.getContext('2d');. Todo se sitúa mediante coordenadas: el origen (0,0) está en la esquina superior izquierda, la X crece hacia la derecha y la Y hacia abajo.
