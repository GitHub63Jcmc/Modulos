3.7 Almacenamiento local con Web Storage

Lección práctica de persistencia de datos

La API Web Storage permite guardar datos en el navegador del usuario de forma persistente y segura sin necesidad de usar cookies. Se divide en dos objetos principales:

  • localStorage: Los datos persisten indefinidamente incluso si se cierra el navegador.
  • sessionStorage: Los datos se eliminan automáticamente cuando se cierra la pestaña o ventana del navegador.

Métodos principales

Para manipular los datos se utilizan métodos sencillos como setItem(clave, valor), getItem(clave), removeItem(clave) y clear().
