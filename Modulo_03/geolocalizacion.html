3.6 API de Geolocalización en HTML5

Lección práctica de APIs nativas

La API de Geolocalización permite a los dispositivos compartir su ubicación geográfica con las aplicaciones web. Por motivos de privacidad y seguridad, el navegador siempre solicitará el consentimiento explícito del usuario antes de revelar la posición.

Métodos principales

  • navigator.geolocation.getCurrentPosition(exito, error, opciones): Obtiene la posición actual una sola vez.
  • navigator.geolocation.watchPosition(exito, error, opciones): Registra una función para ser llamada automáticamente cada vez que la posición del dispositivo cambie.
